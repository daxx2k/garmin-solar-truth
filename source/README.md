# Source modules

SolarTruthApp schedules background collection. SolarLogger maintains the sample ring. SolarDayRollup aggregates daily history. SolarEstimates computes exposure, battery benefit and calibration. SolarTruthView displays TODAY, DETAILS, HISTORY and diagnostics with staged startup work and cached data. SolarTruthDelegate handles controls. FitExport and DebugOutcome support optional diagnostic exports. StabilityTests contains simulator startup regression tests. TodaySolarData intentionally contains no embedded personal readings.
